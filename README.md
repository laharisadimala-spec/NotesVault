# NotesVault 📚

> **Your Notes. Your Knowledge. Your Community.**

NotesVault is a centralised academic resource-sharing platform built for college students. Explore unit-wise notes, previous year question papers, and important questions, or upload and share your own resources to help fellow students.

---

## ✨ Features

- **Unit-wise Notes Library**: Filter by branch, semester, subject, and unit to find exact study materials.
- **Previous Question Papers**: Access archives of past university exam papers.
- **Important Questions**: Curated lists of critical exam questions by topic.
- **Student Dashboard & Profile**: Track your contributions, bookmarks, and activity.
- **Contributor Leaderboard**: Recognition system for students who share high-quality notes.
- **Resource Requests**: Request notes or solutions for specific topics.
- **Light / Dark Mode**: Seamless theme switching for late-night study sessions.
- **Offline / Local Storage**: Browser-based persistent storage for notes, favourites, and ratings.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser — no build steps or backend servers required!

```bash
# Clone the repository
git clone https://github.com/laharisadimala-spec/NotesVault.git

# Navigate into the project directory
cd NotesVault

# Open index.html in your default browser (Windows)
start index.html
```
